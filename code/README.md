# Maison Alba

Website source files are in `code/`; photos and fonts are in the root `assets/` folder. Open `code/index.html` for a local preview, or serve the repository root.

`vercel.json` stays at the root and routes the homepage and source files to `code/`, preserving the public website URL.

Edit `code/config.js` for menus and branding. Sample restaurant details, reviews and form integrations should be customized before launch. Asset sources and font licenses are documented in `assets/README.md`.
